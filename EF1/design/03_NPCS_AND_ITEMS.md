# Part IV — Implementation Notes

**Suggested build order**
1. **Raid 1 (Sunken Grainhall)** — simplest new mechanic, lowest level, validates the raid framework beyond the Barrow.
2. **Questline I quests 1–3** — extends the main story with no new regions required.
3. **Raid 2 + Raid 3** — Pineholt and Thornwood use existing regions.
4. **Questlines II–V** — regional chains, each gated by its raid.
5. **New regions** (Emberreach, Ash Sea, Ninefold Deep, Ashvale Keep) and their raids.
6. **Questline VI + the three endings.**

**Data-shape notes for EF1**
- New NPCs fit the existing `NPCS` array shape: `{ id, name, x, y, color, role, dialogue, wander? }`.
- New monsters fit `MONSTER_TYPES`: `{ name, color, hp, maxHit, xp, drops: [[id, lo, hi, chance?]] }`.
- Raid bosses need a `phases` field the current schema lacks — recommend `{ phases: [{ at: 0.65, mechanic: 'quench' }] }` driven by an HP fraction.
- Raid mechanics (Flame, Heat, Wakefulness, Hull) are all a single shared numeric gauge with thresholds — one reusable `RaidGauge` system covers raids 4, 5, 9, and 10.
- Sound zones (Raid 3) and gravity wells (Raid 8) both need per-tile effect overlays — one reusable `TileEffectField` covers both, plus the Barrow's existing sigils.

**Two systems unlock nine raids.** Build `RaidGauge` and `TileEffectField` first.
